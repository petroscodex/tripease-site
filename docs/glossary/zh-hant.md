# TripEase Traditional Chinese (zh-Hant) glossary

**Status: pending native review.** Not reviewed by a native reader. Working choices behind `lib/l10n/app_zh_Hant.arb` (app) and `i18n/zh-hant.json` (website). Written for Taiwan-style usage; the website contains no Taiwan/Taipei terms (promotional media rule).

Style: informal-polite 你 throughout (no 您); one "tap" verb (點選); 朋友 for friends; Taiwan usage (表單, 當地, 公布, 登記, 倒數計時, 鎖定畫面, 裝置); brands and official form names stay in Latin letters (TripEase, Petros Codex, ETA, eTA, ESTA, TDAC, eSIM, Visit Japan Web).

| English | Traditional Chinese | Why |
|---|---|---|
| Form (arrival / official) | 表單 | The website already used 表單; the app used 表格 (which reads as "table" in Taiwan). Now 表單 in both. |
| Form helper | 表單小幫手 | Was 表格助手/表格小幫手. |
| Arrival card (official name, e.g. TDAC) | 入境卡 | Follows the English official term. |
| Land & Sea (mode) | 陸路與海路 | App already used it; the website now matches instead of leaving "Land & Sea" in English. |
| Air (mode) | 航空 | Parallel to 陸路與海路 / 郵輪. |
| Local (services / apps) | 當地 | Site had mainland-style 本地. |
| Tap | 點選 | Replaces the mix of 點按 / 輕點. |
| Published (hours) | 公布 | Replaces 公佈. |
| Lock Screen / countdown | 鎖定畫面 / 倒數計時 | Replaces 鎖屏 / 倒計時. |
| Register (before you fly) | 登記 | Replaces 登錄. |
| This phone | 這支手機 | Same in app and site (site had 這部手機). |
| Qibla | 麥加方向 | Plain Chinese instead of the unexplained loan word. |
| Move to a new phone | 換到新手機 | Strings were still English in the app. |
