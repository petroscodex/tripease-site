# TripEase German glossary (de)

**Status: pending native review.** Not natively reviewed. These are the working choices behind `lib/l10n/app_de.arb` (app) and `i18n/de.json` (website). Everything here is a proposal for a native reader to confirm or change.

Style rules used throughout: informal "du" everywhere (the app and the site were already "du"; a few leftover "Sie" strings were fixed); calm, plain register; "Handy" rather than "Telefon"; "Reise" (never the English "Trip"); "Wallet" is neuter (das Wallet); adjectives in currency names are lower-case in running text ("der japanische Yen"); brands stay "TripEase" and "Petros Codex"; official form names and acronyms stay Latin (ETA, eTA, ESTA, TDAC, eSIM). The website keeps its existing gender-inclusive forms ("Freund:innen", "Erste:r"); the app uses the plain masculine ("dein Freund"): a native reader should decide whether to align them.

| English | German | Why |
|---|---|---|
| Land & Sea (the mode and page) | Land & Meer | "See" means lake (der See) or sea (die See) and reads oddly; "Meer" is unambiguous. The website previously mixed English "Land & Sea" with "Land & See"; both now say "Land & Meer". **Check with a native reader.** |
| Air (the mode) | Flug | Short tab label, parallel to "Land & Meer". |
| Trip | Reise | The app mixed "Trip" and "Reise"; the website only used "Reise". Now "Reise" everywhere ("Reisedetails", "Reisekarte"). |
| Passport | Pass / Reisepass | "Pass" for short labels, "Reisepass" where a full noun reads better. |
| Passport country | Land deines Passes | Replaces the stiff compound "Passland". |
| Visa-free | visumfrei | Standard. |
| e-Visa | E-Visum | Standard official form. |
| Travel authorisation | Reisegenehmigung | Used for ETA/eTA/ESTA/K-ETA; the acronym stays. |
| Arrival card / e-Arrival Card | Einreisekarte (the official name stays Latin) | Common German term. |
| Entry rules | Einreiseregeln | Plain. |
| Immigration authority | Einwanderungsbehörde | Used where the source speaks of immigration. |
| Travel advisory | Reisehinweis | "Reisewarnung" is the narrow formal term of the Auswärtiges Amt; "Reisehinweis" matches the source's softer meaning. |
| Just landed / I'm landed | angekommen / "Ich bin angekommen" | "Gelandet" is only right for aircraft; the mode is about arriving by any means. |
| Phone | Handy | "Telefon" was mixed in; "Handy" is what people say. |
| Seat / Booking reference | Sitzplatz / Buchungscode | Plain words for the form fields. |
| Free plan / free trial | Gratis-Plan / Gratis-Testphase | Consistent with "Gratismonat". |
| Invite a friend | Weiterempfehlen / Einladungsprogramm | Natural verbs for the referral feature. |
| Try again | Versuche es noch einmal | Fully written imperative ("versuch es" was mixed in). |
| Know if you can go (site) | Finde heraus, ob du einreisen darfst | "Wisse, ..." is stiff and "fahren" was a literal slip for "reisen/einreisen". |
| Be first to land (site) | Als Erste:r dabei | Kept: the pun is dropped and the line says what it does. |
| Money format | 29,99 US$ | German number and currency order. |
