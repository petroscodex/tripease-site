# TripEase Japanese glossary

**Status: pending native review.** Not reviewed by a native reader. These are the working choices behind `lib/l10n/app_ja.arb` (app) and `i18n/ja.json` (website).

Style: です/ます throughout; no stiff "あなたの/あなたが" where Japanese drops the pronoun (お持ちのパスポート, ご自身で); no space between Latin/digits and kana (TripEaseが, 3日前, Proを); brands and official form names stay in Latin letters (TripEase, Petros Codex, ETA, eTA, ESTA, TDAC, eSIM, Visit Japan Web).

| English | Japanese | Why |
|---|---|---|
| Land & Sea (mode) | 陸路・海路 | Already used in the app; kept. Written 「陸路・海路」 in running website text. |
| Air (mode) | 空路 | Parallel to 陸路・海路. |
| Cruise | クルーズ | Standard. |
| Entry requirements / rules | 入国条件 | More natural than 入国要件/入国ルール for a traveller. |
| Arrival form / arrival card | 入国カード | The everyday name (入国カード). Official form names and "フォームヘルパー" are unchanged. |
| Visa | ビザ | Everyday word; 査証 is only the formal term. |
| Visa-free | ビザ不要 | Website now matches the app (was ビザ免除). 「ビザ免除プログラム」(US VWP) is unchanged. |
| Your own country | 自国 | Replaces 「あなたの国」/「私の国」. |
| Your passport | お持ちのパスポート | Drops stiff あなたの. |
| Phone | 端末 (app) / スマホ (website marketing) | Replaces スマートフォン in the app; スマホ is the casual form on the website. |
| Crossing (border) | 検問所 / 国境 | 検問所 for crossing points; フェリー乗り場の検問 for ferry ports. |
| Free months (referral) | 無料特典 + N か月分 / 無料期間 | Replaces the literal 「無料月」. |
| Friends | 友だち | Soft, app-appropriate (not 友人). |
| Subscribe | 登録 | |
| I'm landed | 到着しました | Website text now uses the same label as the app. |
