# TripEase Brazilian Portuguese glossary (pt-BR)

**Status: pending native review.** Not natively reviewed. These are the working choices behind `lib/l10n/app_pt.arb` (app) and `i18n/pt-br.json` (website). Everything here is a proposal for a native reader to confirm or change.

Style rules used throughout: Brazilian Portuguese only (você, "celular", "arquivo", "app"); informal but calm register; curly quotes (“ ”) in running text; "o checklist" (masculine) everywhere; brands stay "TripEase" and "Petros Codex"; official form names and acronyms stay Latin (ETA, eTA, ESTA, TDAC, eSIM, eVisa). The names below were fixed earlier for the app and site (see `pt_br_for_zan.md`) and were NOT changed in this pass, only recorded.

| English | Brazilian Portuguese | Why |
|---|---|---|
| Land & Sea (mode and page) | Terra e Mar | Fixed earlier, same in app and site. Capital M kept to match that decision. **Check with a native reader** (alternatives: "Terra e mar"). |
| Air (mode tab) / Fly (button) | Ar / Voar | Fixed earlier. "Ar" as a tab label is short but could read as "air" the element: **check with a native reader** (alternative: "Voo"). |
| Cruise | Cruzeiro | Unchanged. |
| I’ve landed / I’ve arrived | Cheguei | Both the arrival button and the home tile. |
| Just landed in {country} | Você chegou: {country} | Avoids "para o/para a" problems with country names. |
| Partner picks | Sugestões de parceiros | Replaces "escolhas de parceiros", which read like a literal translation. |
| Customs (border authority) | Alfândega / regras alfandegárias | "Os costumes variam" was a wrong reading of "customs" (habits). |
| Road (crossing type) | Estrada | "Rodoviária" means a bus station in Brazil. |
| Checklist | checklist (masculine) | Mixed "a checklist"/"o checklist" before; now "o checklist". "Lista" is no longer used for the crossing checklists. |
| Travel buddy | Companheiro de viagem | "Parceiro de viagem" can sound like a business partner. |
| Travel advisory | Alerta de viagem | Unchanged.  |
| Passport photo | Foto de passaporte | "Foto 3x4" is a Brazilian ID format and is wrong for foreign passport offices. |
| Wallet (offline) | Carteira de viagem | Unchanged. |
| Stamp map | Mapa de carimbos | Unchanged. |
| Free / Pro | Grátis / Pro | Unchanged. |
| Coming soon | Em breve | Unchanged. |
| Language picker | Português (Brasil) | Unchanged. |
| Official agency names (Immigration New Zealand, Thai Immigration Bureau, ICA, UK Home Office…) | Kept in the original language | Official names are not translated. One row had a half-translated "Immigration Nova Zelândia"; fixed. |
| Online | online | Replaces the older "on-line" spelling. |
| Prices | US$ 29,99 (comma decimal, space after US$) | Brazilian format; applied to page text and the pricing script strings. |
| Just landed (page section) | Você chegou | Same as the app. |
| Go / Apply first / Stop and plan (status tags) | Pode ir / Solicite antes / Pare e planeje | Three-step entry status on the home page. |
| Welcome home (passport matches destination) | Bem-vindo de volta | |
| Not customary (tipping) | Não é de praxe | |
| Partner links / partner suggestions | Sugestões de parceiros | Matches the app. |
| Crossing (border) | Travessia | Road, rail, ferry and foot crossings: rodoviárias, ferroviárias, de balsa e a pé. |
