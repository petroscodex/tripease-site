🇨🇦 Canada

Electronic Travel Authorization (eTA)

Une autorisation de voyage pour les visiteurs dont le passeport ne nécessite pas de visa. Faites la demande sur le site officiel avant d'embarquer.

Ouvrir le site officiel ↗

N'utilisez que le site officiel. Les sites imitateurs copient les formulaires officiels et les font parfois payer. Vérifiez l'adresse avant de saisir quoi que ce soit : elle doit être www.canada.ca.

En bref

Qui est concernéLes visiteurs dont le passeport est concerné par le dispositif. Vérifiez d'abord votre passeport : TripEase vous dit si vous en avez besoin.
StatutObligatoire pour les passeports concernés
Quand le remplirAvant le voyage. Voir le site officiel pour les délais.
CoûtDes frais officiels sont demandés sur le site officiel. Les sites imitateurs y ajoutent leurs propres frais.
Site officielhttps://www.canada.ca/en/immigration-refugees-citizenship/services/visit-canada/eta/apply.html
Géré parImmigration, Refugees and Citizenship Canada

Avant de l'ouvrir

Gardez votre passeport et vos plans de voyage sous la main, puis répondez aux questions directement sur le site officiel. Nous ne reproduisons pas le formulaire ici : seule la version officielle compte, et elle peut changer sans préavis.

Juste du premier coup

TripEase vous dit si votre passeport nécessite eTA, l'ajoute à la liste de votre voyage et vous emmène en un geste vers le formulaire officiel, avec vos informations prêtes à copier. C'est toujours vous qui envoyez, sur le site officiel.

Accès anticipé Vérifiez votre passeport

Informations générales, pas un conseil juridique. Les règles peuvent changer rapidement : vérifiez sur le site officiel ou auprès de votre compagnie aérienne. TripEase n'est affilié à aucun gouvernement. Source : Immigration, Refugees and Citizenship Canada.
